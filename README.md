# Trench Rat 🐀

Trench Rat is a Web3 decentralized application (dApp) built to connect directly with popular Web3 mobile and extension wallets via deep-linking mechanics.

## 🚀 Features
- **Wallet Connection**: Seamless deep-linking support for MetaMask, Coinbase Wallet, Trust Wallet, Rainbow, Phantom, Zerion, and Robinhood Wallet.
- **Responsive UI**: Optimized interface with custom dynamic assets and real-time status indicators.
- **Pure Frontend Architecture**: Built with lightweight HTML, CSS, and Vanilla JavaScript for fast global delivery.
